Connecting to your Home Assistant session…

1 · Connect

Use an administrator account for setup. Dashboard controls use each signed-in person's own Home Assistant permissions.

Generating replaces discovered room, climate, camera, media and calendar mappings in the editor. Save only after reviewing. Advanced settings are retained.

3 · Review and save

Review the JSON below. You can paste an existing DASH_CONFIG object as JSON to retain custom pages, scripts, scenes, cameras, tariffs and other mappings. Remove url and token. Never paste credentials.
